基于 ROS2 + MuJoCo 的双臂 VLA 模仿学习系统

2026.08 – 2026.10

项目负责人· 独立完成· Apache-2.0

解决复用问题：换一种策略不必复制一套 ROS 节点，换一台机械臂不必重写一条控制链路。 把「遥操作采集 → 数据集 → 训练 → 闭环推理」串成一条可以重复跑通的流水线。

遥操作采集→LeRobot 数据集→ACT / SmolVLA / Pi0→MuJoCo 闭环推理
  • 双臂仿真与主从映射：在 MuJoCo 中搭建 SO101 主臂与 UR5e 的仿真环境；对 SO101 做正运动学求解，把夹爪 TCP 位姿逐轴映射到 UR5e 基座坐标系，实现绝对位姿重定向与 IK 校验。
  • 统一策略运行时：按 checkpoint 配置自动识别 ACT / SmolVLA / Pi0，通过机器人适配器让不同机械臂共用同一条控制链路。
  • 数据闭环：基于 MCAP 录制遥操作图像与关节状态并转换为 LeRobot 数据集，完成 ACT 与 SmolVLA 在方块分类、抽屉任务上的在线闭环推理。
